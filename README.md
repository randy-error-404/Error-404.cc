# Error-404.cc

Personal website and professional landing page for Randy.

## What is this?

Error-404.cc is my personal web space, built around two things:

- **Work & IT** — my professional background as a Linux Systems Administrator, including experience, current work, certifications and projects.
- **Digital Hygiene** — a beginner-friendly collection of lessons about passwords, password managers, 2FA, email security and staying safer online.

Professional information, experience, certifications, current focus and projects.

### Digital Hygiene

## Technology

The website is built as a lightweight static site using:

- HTML
- CSS
- JavaScript
- GitHub Pages
- Cloudflare DNS

There is no framework or unnecessary backend.
